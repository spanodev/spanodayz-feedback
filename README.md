# SpanoDayZ Feedback

Este repositório existe para receber **relatos de bugs e sugestões** sobre
o **SpanoDayZ Launcher** — um launcher para DayZ focado em UX limpa,
conexão confiável a servidores moddados e gerenciamento preciso de mods.

## Como reportar um bug

A forma mais fácil é **direto pelo launcher**:

1. Abra o SpanoDayZ Launcher
2. Clique em **🐛 Reportar bug** no menu lateral
3. Preencha o formulário (descrição com no mínimo 10 caracteres)
4. Clique em **Enviar relato**

Pronto. A issue é criada automaticamente aqui, com diagnóstico técnico
(versão, status do Steam, último servidor, últimos 50 eventos do log)
já anexados.

## Posso reportar sem ter conta GitHub?

**Sim.** O fluxo pelo launcher não exige conta. Você só precisa de uma
conta GitHub se quiser **comentar** em uma issue existente ou abrir
uma issue manualmente aqui.

## Posso buscar se meu problema já foi reportado?

Sim — antes de reportar, vale dar uma olhada nas
[issues abertas](../../issues) para evitar duplicatas.

## Acompanhar o status do meu relato

Cada relato gera uma URL única (`/issues/123`) que você pode acessar a
qualquer momento. O link aparece na tela de confirmação do launcher
quando você envia.

## Privacidade

- O launcher **não coleta dados automaticamente**.
- Quando você reporta um bug, o envio inclui apenas o que você digitou
  + diagnóstico técnico (versão, status do Steam, último servidor,
  últimos 50 eventos do log).
- Caminhos do Windows são **sanitizados** antes de serem publicados
  (`C:\Users\<seu-nome>\` vira `C:\Users\<redacted>\`).
- Você decide se deixa um contato pra retorno ou envia anonimamente.

## Para sugerir uma feature

Abra uma [issue nova](../../issues/new) com o label `enhancement`.

## Onde está o código-fonte do launcher?

O launcher é desenvolvido em um repositório separado, hoje privado.
Este repo aqui é apenas para feedback público.
